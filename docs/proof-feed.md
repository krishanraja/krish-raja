# The proof feed: `https://www.krishraja.com/proof.json`

Status: Current
Added: 14 November 2026 (fleet integration, cluster I-08)

The approved proof about Krish, written once on krishraja.com and read by
Control Center, the pitch writers and the voice check. It is generated by
`scripts/generate-static.mts` from the same `src/content/` modules the page,
the JSON-LD and `llms.txt` read, so a fact changes in one place. Nothing in it
is written for it, and `npm test` fails if it drifts from the content layer.

## What it holds

| key | from | what |
|---|---|---|
| `schema`, `version` | fixed | `krishraja.com/proof`, `1`. A reader should refuse a version it does not know. |
| `updated` | `site.updated` | the date the content layer was last revised |
| `person` | `site.ts` | name, headline (the spine), cluster, description, bio, job title, url, photo, email, verified profiles, awards, alumni, education, topics |
| `mindmake` | `portfolio.ts` | name, one line, url |
| `now`, `writing` | `site.ts` | what he does now and where he publishes, as in `llms.txt` |
| `channel` | `home.ts` | Make Your Mind Up: name, line, url, series and days |
| `figures` | `receipts.ts` | the four headline figures with category, metric, context and description |
| `roles` | `receipts.ts` | the commercial track record, one line per employer |
| `credentials` | `receipts.ts` | as listed on the site |
| `sessions` | `deck.ts`, `lessons.ts` | the sessions line, the attendee line and employer names, every Lightning Lesson with its link, and `next` (null until announced) |
| `appearances` | `appearances.ts` | every linked appearance: title, outlet, kind, year, url |
| `contact` | `site.ts` | the published address, the booking link, the enquiry page |
| `retired` | `project-documentation/retired-names.json` | names, URL fragments and spines that must not come back, and brand renames |

## What it never holds

- Anything the site does not publish. The confidential advisory detail in
  FACTS.md ("Named engagements") stays out, because listing it in a public file
  would publish it; the test suite checks the feed for every one of those names.
- Prices, a venture count, ratings: everything on CLAUDE.md's deliberately-absent list.
- Any address, key or server variable; the same guard as the page script.

## Changing the shape

Adding a key is safe. Renaming or removing one breaks readers: bump `version`
and tell Control Center first.
